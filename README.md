# 🔨 Sistema de Leilões

## 📝 Sobre o Projeto

Este projeto consiste no desenvolvimento de um sistema informatizado para automação e gestão das rotinas de uma **Casa de Leilões**. 

O objetivo principal da aplicação é modernizar o controle de lotes, lances e usuários, garantindo maior eficiência operacional, rastreabilidade e integridade nas operações do leilão. A iniciativa faz parte do processo de modernização e digitalização dos serviços da empresa, seguindo boas práticas de qualidade de software, versionamento e segurança.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **[Java](https://www.java.com/)** - Linguagem de programação principal utilizada na regra de negócio do sistema.
* **[SQL / MySQL](https://www.mysql.com/)** - Linguagem de consulta e sistema de gerenciamento de banco de dados para persistência das informações de usuários, lotes e lances.
* **[Git](https://git-scm.com/) / [GitHub](https://github.com/)** - Ferramentas para controle de versão do código-fonte e colaboração.
